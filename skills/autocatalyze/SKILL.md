# 自律実行と常時稼働エージェント

## 役割

常時稼働エージェントの中核。起動、状態の復元、案件選定、必要な専門スキルへの委譲、実装、公開確認、復旧、停止、次の起動まで一元管理する。他のスキルに独立スケジューラーを作らない。LLMを連続実行する必要はない。

## 単発の仕事

1. 依頼と現状、利用者の入口、完了条件を確認する。
2. 最小の変更を実装する。必要な専門スキルの判断だけ一度使い、結果を反映する。
3. 実物を検証してコミット・反映する。公開変更は公開先を読み戻して確認する。
4. 成果、実施した検証、未確認を伝える。形式上の承認待ちで作業を止めない。

## 定時・イベント・再開

1. **起動**：既存のジョブを使い、権限、対象、実行上限を確認する。
2. **復元**：既存の履歴から最後の成功、入力版、処理済み位置、未完の反映と再開条件を読む。同じ更新を二重反映しない。
3. **実行**：差分と影響から案件を選ぶ。定型判定はコードで行い、LLMは判断が必要な部分だけ使う。差分がなければ処理を省く。
4. **検証**：出力先を読み戻す。失敗した工程を特定し、再試行の範囲を限定する。
5. **停止・引き継ぎ**：結果と次の起動条件を既存の記録に残す。不要な一時監視を解除する。

## 完了

単発は使える成果、継続運用は二重実行防止、停止後の再開、公開結果と次回起動が確認できる。未実行を実行済みと報告しない。
