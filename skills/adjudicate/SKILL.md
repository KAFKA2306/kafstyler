# 評価と比較

## 手順

1. 判断する論点、代表入力、必要な合格条件を決める。方式比較は測定前に条件を固定する。
2. 同じ環境と入力で候補の実物を測り、品質、費用、運用負担を比べる。
3. 測定値、誤差、未確認を区別して採否を決める。モデル自身の自己評価を唯一の証拠にしない。
4. 変更後は関係する回帰だけ確かめる。

## 完了

比較条件、結果、採否が再現できる。小さな修正に重い評価票を要求しない。
