# 目的の再定義

## 手順

1. 依頼、現状、制約、利用者の入口を調べる。
2. 完了時に利用者ができる行動と代表入力・期待結果を定める。
3. 現状との差から最小の変更を選ぶ。修正・統合・削除・変更しない案も考える。
4. 完了条件を実行する担当へ渡す。

## 完了

実際の入口から結果を確かめられる。明確な小変更に新しい計画書や台帳を作らない。
