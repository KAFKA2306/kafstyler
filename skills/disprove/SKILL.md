# 反証レビュー

## 手順

1. 疑う前提、実際の利用経路、失敗時の影響を特定する。
2. 原資料と実物で反例を探す。代替方法と削除案も検討する。
3. 再現条件、根拠、影響、対応案を示す。推測や好みを重大欠陥と混同しない。
4. 直せる問題は元の作業で修正し、影響する結果を確認する。

## 完了

重大な指摘の真偽と適用範囲が判別できる。全成果物の一律査読や循環呼び出しはしない。
