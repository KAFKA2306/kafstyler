# 文書校正

任意の出力で人が読む文章には[imozの執筆・推敲ルール](../../BIBLES.md#imozの日本語編集)を適用する。[出力の共通基準](../../MISSION.md#出力の共通基準)

1. あらゆる回答、成果物、文書、PR本文、生成コードのコメントや説明文で[imozの原文](../../BIBLES.md#imozの日本語編集)を参照し、読者、目的、媒体、指定範囲を確かめる。
2. 対象全体を読み、重複、曖昧な評価、意味の切れ目を診断する。文書を編集する場合は修正箇所と方針を整理し、必要な改善を反映する。KAFKA2306のWeb UIでは、[かふかのデザインパターン](../../BIBLES.md#かふかのデザインパターン)から共通の判断パネルを開き、見出し、状態表示、操作ラベルで判断、根拠、次の操作が分かるように校正する。
3. [タイトル・見出し・用語の見直し](#タイトル見出し用語の見直し)を行う。原稿の主張、数値、条件、不確実性、出典を保つ。資料から要約するときは結論を先に示し、判断を支える根拠に一次リンクを付ける。結論に影響する未確認事項を明記する。
4. 完成稿を原典と依頼に照合し、前の会話を知らない読者として通読する。必要な判断材料や次の操作を拾えるか確かめる。手順書の前提、コマンド、リンクは読者の入口から試し、実行できなかった箇所を作業報告で示す。

[共通の連携手順](../../AGENTS.md#コマンドの連携)に従い、校正文を返す前に [`kafstyler:scrutiny`](../scrutiny/SKILL.md) を呼ぶ。 原稿、原典、校正文、読者と用途を渡す。数値、主張の強さ、成立条件が変わっていないか、記載どおりに判断や操作ができるかを確かめ、重大なずれを直す。

校正文かブリーフを返す。別のコマンドに呼ばれた場合は、渡された数値と判断を保ち、校正文を元の作業に返す。読者向けの本文には内容と根拠を置き、作業経過の報告は利用者への応答で扱う。

## タイトル・見出し・用語の見直し

1. タイトルだけで、扱う対象と、本文を読んで分かることやできることが伝わるか確かめる。見出しは並べて読み、目的の情報を探せるか、隣り合う見出しの違いが分かるかを確かめる。本文と照らし、扱う範囲を越えた表現や、抜けていた重要な条件を直す。
2. 本文で繰り返す語、見出しや画面で意味を担う語を拾う。用語の意味と範囲を原典や現行画面で確認し、同じ対象には同じ語を使う。曖昧な名詞句、独自の略語、意味が重なる修飾は、対象や操作が分かる言葉に直す。定着した専門用語、固有名詞、引用、コマンド、識別子は正確な表記を保ち、必要なら初出で短く説明する。
3. 新しく付けるタイトルや変更するタイトルと、解釈が分かれそうな見出し・用語には別案を作る。それぞれを本文と併せて読み、内容の正確さ、読者が普段使う言葉、拾い読みしやすさで選ぶ。見出しを変えたら、目次、相互リンク、参照元で新しい見出しをたどれるか試す。
