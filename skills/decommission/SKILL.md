# 不要な仕組みの削除

## 手順

1. 残す利用者の操作と必要な成果を確認する。
2. 重複・旧版・未使用のコード、文章、規則、フック、CI、テスト、定期処理を探す。
3. 固定パス、自動検出、呼び出し元、公開先、実行中のジョブからの依存を調べる。現役の未確認依存は消さない。
4. 必要な情報を正本へ統合し、不要な箇所と参照元を同じ変更で整理する。
5. 残した入口で成果を確かめ、削減内容と未確認を報告する。

## 完了

必要な機能が使え、余分なものが削除されている。削減件数を目的化しない。削除の代わりに新たな監査を増やさない。
